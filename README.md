# devriz.umbrellaautomation.com

Internal tools for the shop, served by GitHub Pages at
`https://devriz.umbrellaautomation.com/`. The root returns a real 404 on
purpose; each tool lives in its own folder and is reached by its address.

| Folder  | What it is |
| ------- | --- |
| `lmi/`  | The client-facing LogMeIn Installer landing page. Mirror of `frank-umbrella/work/logmein/` so clients can be sent the shorter `/lmi` address. Re-sync with `sync-from-work.ps1` when the source changes. |
| `loadout/` | Loadout, the office inventory and pick-ticket app (moved here from `work/loadout` on 2026-11-05; the old address redirects) |

The company hub stays at its own address; nothing here is linked from it.
